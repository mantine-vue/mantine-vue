Nodes are plain, serializable objects. Their geometry uses diagram world coordinates, and custom
application data belongs in `data` or `meta`.

## Node model

```ts
import type { DiagramNode } from '@mantine-vue/diagram'

const node: DiagramNode = {
  id: 'approval',
  type: 'rect',
  x: 100,
  y: 80,
  width: 160,
  height: 80,
  rotation: 0,
  label: 'Review request',
  style: { fill: 'blue.0', stroke: 'blue.6', cornerRadius: 8 },
  ports: [{ id: 'approved', x: 1, y: 0.5, kind: 'source' }],
  data: { status: 'pending' },
  meta: { recordId: 'request-42' },
}
```

Use `parentId` for groups and `layerId` for layers. `locked` prevents edits, while `hidden` removes
the node from the canvas. `richText`, when present, takes precedence over `label`.

## Custom Vue nodes

A `DiagramNodeType` combines rendering with geometry and interaction behavior. SVG renderers are the
default. Set `html: true` to render regular HTML or Mantine components inside an SVG
`foreignObject`.

<Demo data={DiagramDemos.customNodes} />

Custom renderers receive `node`, `selected` and `controller` props and draw in local coordinates
from `0, 0` to the node's `width, height`. Inputs, buttons and links are excluded from diagram
pointer handling automatically; add `data-diagram-no-pointer` to other interactive descendants.

## Ports

Port coordinates are relative to the node box: `0` is the top or left edge and `1` is the bottom or
right edge. Ports rotate with the node. Set `kind` to `source` or `target`, and use `maxConnections`
to limit how many edges may use the port.

Nodes without explicit ports receive one on each side. Edges may also attach directly to a node
outline. See [connectors and routing](/diagram/connectors) for connection rules.

## Templates and palettes

Templates define a reusable node or a small graph. `DiagramPalette` groups templates by category,
searches their labels and keywords, and inserts them by drag, click or keyboard.

```ts
import type { DiagramTemplate } from '@mantine-vue/diagram'

const templates: DiagramTemplate[] = [
  {
    id: 'process',
    label: 'Process',
    category: 'Flowchart',
    node: { type: 'rect', width: 160, height: 64, label: 'Process' },
  },
  {
    id: 'decision-branches',
    label: 'Decision with branches',
    category: 'Patterns',
    nodes: [
      { type: 'diamond', x: 0, y: 0, label: 'Valid?' },
      { type: 'rect', x: -120, y: 170, label: 'Yes' },
      { type: 'rect', x: 130, y: 170, label: 'No' },
    ],
    edges: [
      { source: 0, target: 1, label: 'yes' },
      { source: 0, target: 2, label: 'no' },
    ],
  },
]
```

Register node types and templates directly on `Diagram`, in `useDiagram`, or as part of a reusable
[diagram extension](/diagram/extensions).
