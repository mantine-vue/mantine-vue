Extensions package custom node types, tools, commands, routers, templates and engine plugins into a
single reusable unit. The [floor plan](/diagram/floor-plans) and
[restaurant](/diagram/restaurant) modules use the same public extension API.

## Create an extension

```ts
import { createShapeTool } from '@mantine-vue/diagram'
import type { DiagramExtension } from '@mantine-vue/diagram'

const networkExtension: DiagramExtension = {
  name: 'network',
  nodeTypes: [serverNode, routerNode],
  tools: [createShapeTool({ id: 'server', node: { type: 'server' } })],
  commands: [pingCommand],
  routers: { bus: busRouter },
  templates: [{ id: 'server', label: 'Server', node: { type: 'server' } }],
  plugins: [auditPlugin],
  setup: (controller) => {
    const stop = watchServerState(controller)
    return () => stop()
  },
}
```

Register extensions in `useDiagram({ extensions: [...] })` or with the `extensions` prop when
`Diagram` owns its controller.

## Custom tools

A `DiagramTool` receives pointer events in world coordinates, the hit target under the pointer, and
keyboard events. Set `edits: true` to make the tool unavailable in `select` and `view` modes.

## Custom commands

Commands provide a stable action ID for toolbars, context menus and keyboard shortcuts.

```ts
import type { DiagramCommand } from '@mantine-vue/diagram'

const pingCommand: DiagramCommand = {
  id: 'ping',
  label: 'Ping server',
  shortcuts: ['mod+P'],
  readOnly: true,
  isEnabled: (editor) => editor.getSelectedNodes().some((node) => node.type === 'server'),
  run: (editor) => ping(editor.getSelectedIds()),
}
```

`readOnly: true` keeps the command available in `select` and `view` modes. Use `isEnabled` to guard
invalid states and call `controller.execute('ping')` from custom UI.

## Engine plugins and hooks

Core plugins run against the framework-independent `DiagramEditor`. Subscribe to `editor.events`
for document commits, selection, viewport and interaction changes. Use `editor.addTransformHook()`
to update related nodes in the same transaction after a move, resize, rotation, paste or drop.

Use `validateTransform` to reject an interactive transform, for example when a node would leave a
required boundary. Keep rendering and Vue lifecycle work in an extension's `setup` callback rather
than in a core plugin.

## Reactive composables

`useDiagramSelection`, `useDiagramHistory`, `useDiagramViewport`, `useDiagramKeyboard` and
`useDiagramExport` accept a controller or read it from the nearest `Diagram` or `DiagramProvider`.

```ts
const { nodes, isEmpty } = useDiagramSelection(controller)
const { canUndo, undo, undoLabel } = useDiagramHistory(controller)
const { zoomPercent, fitView } = useDiagramViewport(controller)
```

Use these composables to build application-specific sidebars and controls without duplicating the
editor's reactive state.
