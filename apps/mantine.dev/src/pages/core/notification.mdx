## Usage

Notification is a base component for the notification system.
Build your own or use the [@mantine/notifications](/x/notifications/) package.

<Demo data={NotificationDemos.configurator} />

## Notifications system features

When used through [@mantine-vue/notifications](/x/notifications/), notifications support close
buttons, horizontal dragging, trackpad swipe dismissal, queues, priorities, stacked layout and
custom rendering. Configure drag and scroll dismissal on the `Notifications` component.

## Accessibility

To support screen readers, set the close button's aria-label or title with `closeButtonProps`:

```vue
<Notification :closeButtonProps="{ 'aria-label': 'Hide notification' }" />
```
