## Usage

`Toggle` is a button that can be toggled between active and inactive states.
It is a polymorphic component and can be rendered as any element.

<Demo data={ToggleDemos.usage} />

## Controlled and uncontrolled

Use `defaultActive` to set the initial state of an uncontrolled `Toggle`, and
`v-model:active` to control it.

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { Toggle } from '@mantine-vue/core'

const active = ref(false)
</script>

<template>
  <!-- Uncontrolled -->
  <Toggle defaultActive />

  <!-- Controlled -->
  <Toggle v-model:active="active" />
</template>
```

## Accessibility

`Toggle` renders a `button` element with `aria-pressed` that reflects the active state.
When using icon-only toggles, provide an `aria-label` so screen readers can announce its purpose.

When rendered as a non-button element, `disabled` sets `aria-disabled`, removes the element from
the tab order, and prevents clicks.
