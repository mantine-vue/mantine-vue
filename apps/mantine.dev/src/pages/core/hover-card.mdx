## Accessibility

`HoverCard` supports keyboard focus and exposes the dropdown as an accessible popover. The target
receives `aria-expanded`, `aria-controls`, and `aria-haspopup`, while the dropdown uses
`role="dialog"`. Press Escape to close an opened card. Use the `events` prop to control hover,
focus, and touch activation independently.
