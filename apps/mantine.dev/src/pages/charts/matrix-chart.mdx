## Usage

`MatrixChart` is a categorical x/y heatmap. Data items contain `x`, `y` and a numeric `value`;
use `null` for empty cells.

<Demo data={MatrixChartDemos.usage} />

## Data format

```ts
interface MatrixChartCell {
  x: string
  y: string
  value: number | null
}
```

## Labels

Supply `xLabels` and `yLabels`, or let the component infer their first-seen order from data.
Use `withXLabels`, `withYLabels` and `xLabelsPosition` to control visibility and placement.
