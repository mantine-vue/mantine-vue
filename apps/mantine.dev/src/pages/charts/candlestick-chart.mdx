## Usage

`CandlestickChart` displays open, high, low and close values. Rising candles use `upColor`,
falling candles use `downColor`; the wick spans low to high and the body spans open to close.

<Demo data={CandlestickChartDemos.usage} />

The y-axis domain is based on the lowest low and highest high instead of starting at zero.
Override it through `yAxisProps` when needed.

## Data

Each item contains the x-axis value and four numeric OHLC values:

```ts
interface CandlestickChartData {
  date: string
  open: number
  high: number
  low: number
  close: number
}
```
