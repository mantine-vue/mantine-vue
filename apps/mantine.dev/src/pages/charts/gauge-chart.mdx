## Usage

`GaugeChart` displays a single value on a radial arc for KPIs, utilization and status indicators.
The arc fills from `min` (`0`) to `value`, and the formatted value appears in the center.

<Demo data={GaugeChartDemos.usage} />

## Sections

`sections` divides the arc into threshold bands. Each section fills from the previous upper bound
to its own `value`; the last section should end at `max`. Sections are sorted automatically.
With sections, use `target` to mark the current value.

<Demo data={GaugeChartDemos.sectionsProp} />

## Target marker

`target` draws a marker across the arc. Configure it with `targetColor` and `targetSize`.

<Demo data={GaugeChartDemos.target} />

## Start and end angle

Angles use degrees where zero is the top and positive values move clockwise. A span of at least
360° produces a full circle; an end angle below the start sweeps counter-clockwise.
