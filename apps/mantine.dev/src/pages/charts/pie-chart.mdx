## Usage

`PieChart` displays proportional data. Each data item requires `name` and `value` and can define a Mantine color.

<Demo data={ChartsDemos.pieChart} />

## Labels and legend

Enable `withLabels` and `withLabelsLine` to display segment labels and connector lines. Use `labelsPosition="outside"` to place labels around the chart and `labelsType="percent"` for percentage values.

Labels and the legend are controlled independently. Set `withLegend` only when the legend should be displayed.
