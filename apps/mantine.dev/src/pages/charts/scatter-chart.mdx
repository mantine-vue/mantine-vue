## Usage

`ScatterChart` plots the relationship between two numeric values. Set `xAxisKey` and `yAxisKey` to select fields from the data.

<Demo data={ChartsDemos.scatterChart} />

## Multiple series

Provide multiple series with distinct names and colors to compare groups. Axis, tooltip, legend, grid, and value-formatting props match cartesian charts.

## Right y-axis

Set `withRightYAxis` and assign `yAxisId: 'right'` to a series to plot it against a second
y-axis. Configure that axis with `rightYAxisProps` and `rightYAxisLabel`.

<Demo data={ChartsDemos.scatterChartRightYAxis} />

## Reference areas and dots

Scatter charts also accept `referenceAreas` and `referenceDots` for range highlighting and
point annotations.
