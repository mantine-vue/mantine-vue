## Usage

`JsonViewer` is an interactive component for viewing JSON structures.

`JsonViewer` displays values the way `JSON.stringify` serializes them: values that implement
`toJSON()` (for example, `Date`) are displayed as the result of `toJSON()`, and `Map` / `Set` are
displayed as empty objects.

<Demo data={JsonViewerDemos.usage} />

## Default expand depth

Use `defaultExpandDepth` to control how many levels are expanded by default. The root node is
always expanded. With `1` (default), nested objects and arrays of the root node are collapsed.

<Demo data={JsonViewerDemos.expandDepth} />

`defaultExpandDepth` is applied only when the component mounts. If `value` is loaded later, change
the `key` together with the data to apply it again, or control expanded state with
`v-model:expandedPaths`:

```vue
<script setup lang="ts">
import { JsonViewer } from '@mantine-vue/code-highlight'

defineProps<{ data: unknown }>()
</script>

<template>
  <JsonViewer :key="JSON.stringify(data)" :value="data" :defaultExpandDepth="2" />
</template>
```

## Long arrays and objects

Use `maxDisplayLength` (`100` by default) to limit the number of entries displayed for a single
object or array. The remaining entries are replaced with a "... N more items" row.

Set `groupArraysAfterLength` to split longer arrays into collapsible `[start...end]` groups instead.
`maxDisplayLength` does not apply to grouped arrays.

## Collapse long strings

Use `collapseStringsAfterLength` to truncate long strings. Truncated strings display a "show more"
button that reveals the full value.

String values longer than 20 characters wrap onto multiple lines. These values have a `data-wrap`
attribute; use it to change wrapping behavior with the [Styles API](/styles/styles-api).

## Keyboard navigation

`JsonViewer` supports keyboard navigation similar to the [Tree](/core/tree) component:

- `↑` / `↓` – move focus between visible nodes
- `→` – expand a collapsed node, or move focus to its first child
- `←` – collapse an expanded node, or move focus to its parent
- `Enter` / `Space` – toggle expand/collapse on collapsible nodes, trigger `valueSelect` on primitive nodes
- `Ctrl + C` / `⌘ + C` – copy the focused node value when `withCopy` is set

## Accessibility

`JsonViewer` renders its content as an ARIA tree. `rootName` is used as the accessible name of the
tree; when it is not set, the tree is labelled `JSON`.

The component is always rendered left-to-right, regardless of the [direction](/styles/rtl) of the
application.
