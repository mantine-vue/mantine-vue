## Installation

<InstallScript packages="@mantine-vue/qr-code @mantine-vue/core @mantine-vue/hooks qrcode" />

Import package styles after core styles:

```ts
import '@mantine-vue/core/styles.css'
import '@mantine-vue/qr-code/styles.css'
```

You can import `@mantine-vue/qr-code/styles.layer.css` instead to place styles in the
`mantine-qr-code` CSS layer.

## Error correction

QR codes support L (7%), M (15%), Q (25%), and H (30%) error correction. Higher levels tolerate
more damage or obstruction but produce denser codes.

<Demo data={QRCodeDemos.errorCorrection} />

## Image overlay

Set `image` to place a logo at the center. `imageSize`, `imageRadius`, `imagePadding`, and
`imageExcavate` control its presentation. Use `errorCorrectionLevel="H"` when overlaying images.

<Demo data={QRCodeDemos.withImage} />

## Download

`useQRCodeDownload` exports SVG, PNG, JPEG, or WebP. Its callback `ref` is passed to the Vue-specific
`rootRef` prop. Raster output uses a scale of 4 by default for high-resolution downloads.

<Demo data={QRCodeDemos.download} />

`getDataUrl` returns the same output as a data URL for uploads, previews, or custom download flows.

## Use cases

string.

<Demo data={QRCodeDemos.useCases} />

## Accessibility

Generated codes render as an SVG image with an accessible label containing the encoded value. An
empty value or a value too large for the selected error-correction level renders an empty SVG rather
than throwing during render.
