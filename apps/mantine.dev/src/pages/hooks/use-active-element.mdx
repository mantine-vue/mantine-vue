## Usage

`use-active-element` reactively tracks
[document.activeElement](https://developer.mozilla.org/en-US/docs/Web/API/Document/activeElement)
– the element that currently has focus. The returned readonly ref is updated every time focus moves
to another element:

<Demo data={UseActiveElementDemos.usage} />

## Definition

```ts
interface UseActiveElementOptions {
  /** If set, pierces shadow roots to return the truly-focused element inside web components,
   *  true by default */
  deep?: boolean

  /** If set, updates the returned element when the active element is removed from the DOM,
   *  true by default */
  triggerOnRemoval?: boolean
}

function useActiveElement<T extends Element = Element>(
  options?: MaybeRefOrGetter<UseActiveElementOptions | undefined>,
): Readonly<Ref<T | null>>
```

Options can be a plain object, a ref or a getter – the hook resubscribes when `deep` or
`triggerOnRemoval` change.

## Shadow DOM

When focus is inside a [web component](https://developer.mozilla.org/en-US/docs/Web/API/Web_components),
`document.activeElement` returns the host element. By default, the hook returns the element
that is focused inside the shadow root. Set `deep: false` to get the host element instead:

```vue
<script setup lang="ts">
import { useActiveElement } from '@mantine-vue/hooks'

// Returns the host element instead of the focused element inside its shadow root
const activeElement = useActiveElement({ deep: false })
</script>
```

## Trigger on removal

Focus events are not dispatched when the focused element is removed from the DOM.
By default, the hook uses [MutationObserver](https://developer.mozilla.org/en-US/docs/Web/API/MutationObserver)
to update the value in this case. Set `triggerOnRemoval: false` to disable it:

```vue
<script setup lang="ts">
import { useActiveElement } from '@mantine-vue/hooks'

const activeElement = useActiveElement({ triggerOnRemoval: false })
</script>
```

## TypeScript

The hook accepts a generic type argument for the returned element. It defaults to `Element`,
narrow it if you know the type of the focused element in advance:

```vue
<script setup lang="ts">
import { useActiveElement } from '@mantine-vue/hooks'

// activeElement is typed as Readonly<Ref<HTMLInputElement | null>>
const activeElement = useActiveElement<HTMLInputElement>()
</script>
```

`UseActiveElementOptions` type is exported from the `@mantine-vue/hooks` package, you can import it
in your application:

```ts
import type { UseActiveElementOptions } from '@mantine-vue/hooks'
```
