## Usage

`EmojiPicker` displays a searchable emoji grid with category navigation, skin tone selector,
and emoji preview. Emoji data is passed with the `data` prop, see the
[Getting started](/emoji/getting-started) page for setup instructions.

## Controlled search

Use `v-model:search-value` to control the search input value:

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { EmojiPicker } from '@mantine-vue/emoji'
import { emojiData } from './emoji-data'

const search = ref('')
</script>

<template>
  <EmojiPicker v-model:search-value="search" :data="emojiData" />
</template>
```

## Unsupported emoji detection

Set `with-unsupported-detection` to hide emojis that are not supported by the current browser
or operating system. To detect support, each emoji is drawn on a canvas.

```vue
<template>
  <EmojiPicker :data="emojiData" with-unsupported-detection />
</template>
```

## Accessibility

The emoji grid uses the `grid` role, the active emoji is announced with `aria-activedescendant`.
Use the `labels` prop to translate `aria-label` attributes.
