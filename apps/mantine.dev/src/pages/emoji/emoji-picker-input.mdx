## Controlled

The value is an emoji ID (a key in `data.emojis`). Use `v-model` to control it.
When the value is not selected in the picker, the input displays the emoji without skin tone:

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { EmojiPickerInput } from '@mantine-vue/emoji'
import { emojiData } from './emoji-data'

const value = ref<string | null>(null)
</script>

<template>
  <EmojiPickerInput v-model="value" :data="emojiData" placeholder="Select emoji" />
</template>
```

## Controlled dropdown

Use `v-model:opened` to control the dropdown state:

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { EmojiPickerInput } from '@mantine-vue/emoji'
import { emojiData } from './emoji-data'

const opened = ref(false)
</script>

<template>
  <EmojiPickerInput v-model:opened="opened" :data="emojiData" placeholder="Select emoji" />
</template>
```

## emojiSelect event

`v-model` stores the emoji ID. Use the `emoji-select` event to get the full emoji object
with name, keywords and skin variants:

```vue
<template>
  <EmojiPickerInput :data="emojiData" @emoji-select="(emoji) => console.log(emoji.emoji)" />
</template>
```
