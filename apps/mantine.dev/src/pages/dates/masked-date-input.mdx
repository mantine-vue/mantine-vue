## Usage

`MaskedDateInput` is similar to [TimePicker](/dates/time-picker) but for dates.
It provides individual masked input fields for day, month, and year with an optional
calendar dropdown for date selection.

<Demo data={MaskedDateInputDemos.usage} />

## Controlled

The `MaskedDateInput` value is a string in `YYYY-MM-DD` format (for example `2000-06-15`).
When `with-time` is set, the value uses `YYYY-MM-DD HH:mm:ss` format (for example `2000-06-15 14:30:00`).
`null` is used to represent no value. The model value is updated when all fields are filled
or when all fields are cleared.

## Get refs

Inner inputs are exposed with a template ref: `dayInput`, `monthInput`, `yearInput`, `hoursInput`,
`minutesInput`, `secondsInput` and `amPmInput`. The exposed `focus(field)` and `clear()` methods can be
used to control the component:

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { MaskedDateInput } from '@mantine-vue/dates'

const input = ref<InstanceType<typeof MaskedDateInput> | null>(null)
const focusYear = () => input.value?.focus('year')
</script>

<template>
  <MaskedDateInput ref="input" label="Date" />
</template>
```

## Focus and blur events

The `focus` event is emitted when one of the inputs receives focus and `blur` is emitted when focus
leaves all inputs:

```vue
<template>
  <MaskedDateInput @focus="console.log('Focused')" @blur="console.log('Blurred')" />
</template>
```

## Accessibility

Each field has an English `aria-label` by default (Day, Month, Year, Hours, Minutes, Seconds, AM/PM),
and the fields are grouped under the `label`. Use the corresponding props to translate the labels.
Also set an `aria-label` for the clear button if `clearable` is used:

```vue
<template>
  <MaskedDateInput
    label="Fecha de nacimiento"
    day-input-label="Día"
    month-input-label="Mes"
    year-input-label="Año"
    :clear-button-props="{ 'aria-label': 'Borrar fecha' }"
  />
</template>
```
