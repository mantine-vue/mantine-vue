## QuarterPicker props

`QuarterPickerInput` supports most of the [QuarterPicker](/dates/quarter-picker/) props.
Read through the [QuarterPicker](/dates/quarter-picker/) documentation to learn about all component features that are not listed on this page.

## Usage

The value is a date string in `YYYY-MM-DD` format pointing to the first day of the selected quarter:

## Presets

Use the `presets` prop to add custom quarter presets. Presets are displayed next to the calendar:

<Demo data={QuarterPickerInputDemos.presets} />

To use `presets` with `type="range"`, define the value as a tuple of two dates:

<Demo data={QuarterPickerInputDemos.presetsRange} />

## Keyboard interactions

The dropdown supports the same keyboard interactions as [QuarterPicker](/dates/quarter-picker/#keyboard-interactions).
When the dropdown is closed after a keyboard interaction (for example, a quarter is selected with `Enter`),
focus is returned to the input.

## Open picker in modal

By default, [QuarterPicker](/dates/quarter-picker/) is rendered inside [Popover](/core/popover/).
You can change that to [Modal](/core/modal/) by setting `dropdown-type="modal"`:

<Demo data={QuarterPickerInputDemos.modal} />
