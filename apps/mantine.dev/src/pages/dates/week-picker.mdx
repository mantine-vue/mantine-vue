## Usage

`WeekPicker` renders the same calendar as [DatePicker](/dates/date-picker/), but selects whole weeks:
hovering any day highlights its week and clicking selects it. Week numbers are always displayed.

<Demo data={WeekPickerDemos.usage} />

## Week value

The value is a date string in `YYYY-MM-DD` format that points to the first day of the selected week.
The first day of the week is determined by the `firstDayOfWeek` prop or by the
[DatesProvider](/dates/getting-started/) settings (Monday by default). Use `getStartOfWeek` and `getEndOfWeek`
exported from `@mantine-vue/dates` to get the week boundaries from the value.

<Demo data={WeekPickerDemos.weekValue} />

## Allow deselect

Set `allow-deselect` to allow users to deselect the currently selected week by clicking on it.
`allowDeselect` is disregarded when the `type` prop is `range` or `multiple`. When a week is
deselected, the model value is set to `null`.

<Demo data={WeekPickerDemos.deselect} />

## Multiple weeks

Set `type="multiple"` to allow users to pick multiple weeks:

<Demo data={WeekPickerDemos.multiple} />

## Weeks range

Set `type="range"` to allow users to pick a weeks range. The value is a tuple of the first day of the
first week and the first day of the last week:

<Demo data={WeekPickerDemos.range} />

## First day of week

Set the `first-day-of-week` prop to change which day starts the week (0 – Sunday, 6 – Saturday). It changes both the
calendar layout and the value that is emitted:

<Demo data={WeekPickerDemos.firstDayOfWeek} />

## Week controls

Week numbers are rendered as buttons: clicking a week number selects the week, and only week numbers are in the
tab order – use `ArrowUp` and `ArrowDown` to move between weeks. Use the `getWeekControlProps` function to add props
to week controls, for example to change `aria-label` or to disable specific weeks:

<Demo data={WeekPickerDemos.weekControlProps} />

## Presets

Use the `presets` prop to add custom week presets. Presets are displayed next to the calendar.
Any date inside the week can be used as a preset value:

<Demo data={WeekPickerDemos.presets} />

To use `presets` with `type="range"`, define the value as a tuple of two dates:

<Demo data={WeekPickerDemos.presetsRange} />

## Accessibility

### Keyboard interactions

Note that the following events will only trigger if focus is on a week control. When the target
week is not displayed, the calendar switches to the previous/next month.
