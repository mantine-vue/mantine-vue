`@mantine-vue/file-manager` provides a backend-agnostic file manager for Vue 3. It includes folder
navigation, five views, previews, uploads, bulk operations, keyboard navigation and a responsive
touch interface. An adapter connects those features to your API or storage service.

## Installation

<InstallScript packages="@mantine-vue/file-manager @mantine-vue/dropzone" />

Import the package styles after the core styles at the root of your application:

```ts
import '@mantine-vue/core/styles.css'
import '@mantine-vue/file-manager/styles.css'
```

## Create your first file manager

Start with `createMemoryAdapter`. It implements the complete adapter contract without a server,
which makes it useful for prototypes, tests and component previews. Its data is reset when the
page reloads.

`FileManager` fills its container, so the container must have an explicit height.

<Demo data={FileManagerDemos.usage} />

## Connect your backend

Use one of three adapter approaches:

- Implement `FileSystemAdapter` for any API or storage service.
- Use `createRestAdapter` when your HTTP API follows the package's REST convention.
- Keep `createMemoryAdapter` for local examples and tests.

Only `list` is required. Optional methods enable matching features, so a read-only adapter does
not expose upload, rename or delete actions. See [backend adapters](/file-manager/adapters) for the
contract, capability detection and REST endpoints.
