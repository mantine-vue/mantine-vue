## Known limitations

- Dragging a rectangle to select entries is not supported. Use Shift/Ctrl clicks or keyboard
  selection.
- Internal drag and drop requires a pointer and is disabled in compact mode. The **Move to** action
  is available for touch and keyboard users.
- Entries cannot be dragged between separate `FileManager` instances.
- The tree view loads all children of each expanded folder instead of paginating them.
- Backend search displays the first result page returned by the adapter.
- Undo history is stored in memory and is cleared when the page reloads.
- PDF rendering depends on the browser's built-in PDF viewer.
- Audio and video previews require a format the browser can play; the package does not transcode
  media.

For deployment guidance, continue with [uploads](/file-manager/uploads),
[previews](/file-manager/previews) and [mobile and accessibility](/file-manager/mobile).
